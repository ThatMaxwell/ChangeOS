Where it stands

  1. Base picked

    Android 17 generic system image (x86_64), checksum verified.

  2. Image built

    Debloated, Aurora and Firefox baked in, boot animation and branding applied, packed into an emulator disk.

  3. First boot

    Booting in the cloud on GitHub Actions, since the build PC's CPU is too old for the Android 17 emulator.

  4. SystemUI and launcher

    The ring status icon, Fog home screen and quick panel, as overlays and a ChangeOS launcher.

  5. Real phones

    An arm64 build for phones with an unlockable bootloader.
