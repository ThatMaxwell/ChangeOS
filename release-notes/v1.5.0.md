The Halloween edition. Same ChangeOS as 1.0 Sweet Vanilla, dressed up for October.

![Pumpkin Caramel home](https://raw.githubusercontent.com/ThatMaxwell/ChangeOS/main/media/pumpkin-caramel/home-pumpkin.png)

## What's new

- **Pumpkin theme**: a night-brown home screen with caramel text and a pumpkin-orange accent that the whole system follows.
- **Pumpkin icon pack**: every app tile is a pumpkin, with the app's icon carved into it.
- **Pumpkin-ring boot animation**: the ChangeOS ring turns orange and grows a stem.
- On this edition the Pumpkin theme is the default. Hold the home screen to switch back to Fog, Graphite or Loud at any time. The Pumpkin theme is also in the theme picker on every build.

Everything else is the same as Sweet Vanilla: Aurora Store, Firefox, Termux, the status ring, and the Play ban.

## Downloads

| File | What it is |
|---|---|
| `ChangeOS-1.5.0-x86_64-system.img.zst` | The full Pumpkin Caramel system image (x86_64), compressed with zstd. |
| `ChangeOSLauncher-1.5.0.apk` | The launcher on its own, with the Pumpkin theme. |

To run it, follow the steps in the [1.0 release notes](https://github.com/ThatMaxwell/ChangeOS/releases/tag/v1.0.0). Building it yourself instead? Set `CHANGEOS_EDITION=pumpkin` before running `python3 build/patch_gsi.py`.

![Pumpkin-ring boot animation](https://raw.githubusercontent.com/ThatMaxwell/ChangeOS/main/media/pumpkin-caramel/boot-pumpkin.gif)

## Known limits

The same as 1.0: x86_64 emulator only for now, with arm64 for real phones coming next.
