The first ChangeOS. Android 17 with nothing you didn't ask for.

![Sweet Vanilla home](https://raw.githubusercontent.com/ThatMaxwell/ChangeOS/main/media/sweet-vanilla/home-status-chip.png)

## What's in Sweet Vanilla

- **ChangeOS Launcher**: Fog home screen with a date card, monochrome icons tinted by your accent, a labeled dock and an app drawer. Themes: Fog, Graphite and Loud.
- **System-wide accent**: pick a color and Android's own color engine follows it, so quick settings and Settings match.
- **Status chip**: battery %, signal and Wi-Fi drawn as the ChangeOS ring in the status bar.
- **Two apps preinstalled**: Aurora Store and Firefox, plus Termux as the built-in terminal.
- **Google Play is banned**: if it ever gets installed, ChangeOS removes it.
- **Debloated**: stock browser, calendar, clock, gallery, music, search and more are gone.
- **Quiet by default**: silent boot, no click sounds.
- **Custom boot animation**: the ring draws itself in.

## Downloads

| File | What it is |
|---|---|
| `ChangeOSLauncher-1.0.0.apk` | The launcher, signed with the ChangeOS key. Install it to `/system/priv-app/ChangeOSLauncher/`. |
| `bootanimation.zip` | Goes in `/system/media/`. |
| `privapp-permissions-changeos.xml` | Goes in `/system/etc/permissions/`. |
| `changeos-ecm.xml` | Goes in `/system/etc/sysconfig/`. Lets the status ring run. |

## Getting the full system image

The image is built from Google's Android 17 GSI, which you download from Google under their terms, so it isn't hosted here. Build it yourself with the scripts in this repo:

1. Get the stable Android 17 x86_64 AOSP GSI from Google's GSI releases page.
2. On Linux (or WSL): `bash build/prep_image.sh`, then `python3 build/patch_gsi.py`.
3. For the emulator, run `python3 build/make_avd_image.py` with the Android 17 `google_apis` x86_64 image installed.

The GitHub Actions workflow in `.github/workflows/boot.yml` does all of this end to end.

## Known limits

- **x86_64 emulator only** for now. An arm64 build for real phones is next.
- In the Android emulator, a graphics-driver bug can restart the system when something reads screen pixels. Real phones don't have this driver.
- Android 17's stock battery icon can't be removed without rebuilding SystemUI. The status chip sits on top of it.
